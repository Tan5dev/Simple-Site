Hi this is my site it is an about-me page where I can show my skills and experience describe my projects and experience and show what skills I am currently learning

I started working on this on 29.08.2026 building the base of the site and filling it with my own content The process I usually follow is thinking about how I would like the website to be and opening VS Code and building the website bit by bit

My first site was built using the VS Code inspired theme which I loved and I thought would be a perfect portfolio for any developer However I faced a great challenge of constantly trying to improve and update the theme without outside help such as AI

Instead of forcing it I decided to change the theme and go with the current one which I find aesthetically pleasing and easier to work with as I can develop it myself

Once I got to a stage where I was happy with the appearance of the site I decided to deploy it to GitHub Pages However I faced what I believe to be the frustrating error of all time

The font and background images of my website were not shown not displayed and not found on the server The website looked broken and I spent nearly two hours trying to find what the issue could be checking the files the CSS GitHub pages and almost everything else I could think of

In the end I discovered the issue was in the way I tried to link my style.css sheet to the HTML documents

As I put my style.css file in the assets/css folder I had to write the path as assets/css/style.css not as /assets/css/style.css as GitHub Pages would try to look for the file in the root directory which is the main folder of the repository Not the subdirectories such as assets/css

It was one of those errors that made me questioning my life choices for two hours before realizing that the error was in one folder

Although that might have been one of the most stressful situations I have ever had to deal with it has also taught me to be careful with file paths and relative paths

Another thing I would like to note is that I used AI while developing this project as a co-pilot to design and suggest features CSS code debugging solutions and more However I was the one making the decisions and changes to the website

What I like about this project is that it is not just a generic portfolio for any developer but something that can grow with me learning new skills and creating new projects

The site, for now is complete. I will continue working on it and expanding it for as long as I continue my development as a web developer More projects more skills more issues to debug and more bugs to fix and more stress to panic about
